NEXUS Cyber Launcher

Launcher Android com visual futurista cyberpunk.

Objetivo

Criar uma interface para o Samsung Galaxy com:

- Tema escuro futurista.
- Detalhes em verde neon.
- Acesso rápido aos aplicativos.
- Interface inspirada em tecnologia e cibersegurança.

Compilação

O projeto será preparado para gerar um APK Android usando GitHub Actions.
